# Suporte do Lume

Página de suporte do app **Lume: Backup de Fotos**: tutoriais em vídeo (Mac e Windows), passo a passo para NAS, perguntas frequentes e contato.
Site estático (HTML e CSS puros, sem scripts nem serviços de terceiros), publicado pelo GitHub Pages: https://rafaeltissot.github.io/lume-suporte/
